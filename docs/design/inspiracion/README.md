# Inspiración: menú de Delicias Dominicanas

Capturas de https://deliciasdominicanas.net/menu/ para tomar ideas de layout y UX (no se copia su marca, textos ni fotos).

El sitio bloquea los navegadores automáticos, así que las capturas se agregan a mano: escritorio (1280 px) y móvil (390 px), con nombres como `desktop-menu.png` y `mobile-menu.png`.
